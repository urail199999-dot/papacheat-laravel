# PAPACHEAT — Laravel 13

Рабочая версия магазина: аккаунты, каталог в БД, разделы/подразделы, редактор товаров, галереи, заказы, чат с изображениями/видео, уведомления и счётчик онлайна.

## Windows / Docker Desktop

Из PowerShell в папке проекта:

```powershell
.\start.ps1
docker compose exec app php artisan shop:admin
```

Если политика компьютера запрещает запуск скриптов, выполните команды из `start.ps1` вручную. Пароль администратора задаётся интерактивно (минимум 12 символов); стандартного пароля нет. Логин администратора строго `urail1999`, публичная регистрация этого логина запрещена. На существующей базе команда назначает права только этому аккаунту.

- Магазин: http://localhost:8080
- Вход по логину или email: http://localhost:8080/login
- Управление магазином: http://localhost:8080/manage
- `/admin` перенаправляет на `/manage`, если локально не установлен другой обработчик Filament.

Filament, установленный ранее на другом компьютере, отсутствует в этом репозитории. Эта версия предоставляет отдельную рабочую панель магазина `/manage`; она не требует Filament. Не заменяйте `composer.json` и `bootstrap/providers.php` в изменённом локальном проекте без резервной копии. Для проверки скачайте эту версию в отдельную папку; старые контейнеры сначала остановите через `docker compose down` (без `-v`). База старого Compose-проекта автоматически в новую папку не переносится.

## Данные

MariaDB хранится в Docker volume. Не запускайте `docker compose down -v`, если нужны данные. `shop:import` переносит старый `storage/app/products.json`, если каталог в БД пуст. Иначе создаёт исходные товары. Повторный импорт не перезаписывает каталог. Заказы старой демонстрационной версии, которые хранились только в сессии, автоматически перенести нельзя.

Товары, статусы и цены отображаются из БД, включая каталог. Скрытые товары нельзя открыть или купить по прямой ссылке. Администратор может смотреть скрытый товар. Раздел с товарами или подразделами удалить нельзя до их перемещения. Имя, цена и срок заказа сохраняются отдельно от товара.

Для смены статуса нужно взять заказ в обработку. Архивация убирает его из списка администратора. Полное удаление истории разрешено только для завершённых/невыполненных заказов с подтверждением. Покупатель видит только свои заказы и файлы; чат доступен ему и единственному администратору.

## Оплата СБП

В `.env` задайте `SBP_PAYMENT_URL` платёжной ссылкой Т-Банка. Перезапустите PHP: `docker compose restart app`. Кнопка «Я оплатил» отправляет заявку на ручную проверку, а не подтверждает перевод. Только администратор меняет оплату на «Подтверждена» после проверки банка. Банковский API/webhook и автоматическая выдача ключей не подключены.

## Файлы, уведомления и онлайн

Скриншоты товаров: JPG/PNG/WebP до 5 МБ, до 8 на товар. Вложения чата: JPG/PNG/WebP/MP4/WebM до 50 МБ. Вложения хранятся приватно и выдаются через авторизованный маршрут. Уведомления/чат проверяются раз в 15 секунд. Звук включается кнопкой после действия пользователя. Онлайн — активные сессии браузеров за 90 секунд, а не число уникальных людей.

## Проверка

```sh
composer install
php artisan test
```

Тесты используют отдельную SQLite in-memory БД. Для разработки в контейнере с тестами нужен `pdo_sqlite`; в composer:2 он есть. Продакшен-контейнер использует MariaDB. Секреты и пароли не коммитятся. Применение обновлений на компьютере пользователя требует локального запуска команд: окружение ChatGPT не имеет доступа к его диску.
